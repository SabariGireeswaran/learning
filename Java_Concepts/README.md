# Java Concepts — Beginner Examples

This folder contains small, easy-to-read Java examples that demonstrate core Java concepts without overwhelming complexity. Each file has a `main` method so you can compile and run the example directly.

How to run

1. Open a terminal in this folder.
2. Compile all examples:

   javac *.java

3. Run a specific example (replace ExampleClass with the file's class name):

   java ExampleClass

Files included

- `HelloWorld.java` — simple program
- `VariablesAndTypes.java` — primitives and basic operations
- `ControlFlow.java` — if, switch, loops
- `Methods.java` — static and instance methods, overloading
- `ClassesAndConstructors.java` — class with constructor and methods
- `InheritancePolymorphism.java` — inheritance and method overriding
- `InterfacesAndAbstract.java` — interfaces and abstract classes
- `Exceptions.java` — try/catch and a custom exception
- `CollectionsExample.java` — List, Set, Map basics
- `FileIOExample.java` — simple file write/read
- `GenericsExample.java` — basic generics
- `ThreadsExample.java` — simple threading with Runnable
