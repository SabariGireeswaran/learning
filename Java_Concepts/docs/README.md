# Java Concepts — Documentation

This `docs/` folder contains short, beginner-friendly explanations of the concepts demonstrated by the example Java files in this project. Each doc links to the example file you can compile and run.

Files

- `oop.md` — classes, constructors, inheritance, and polymorphism
- `control_flow.md` — if, switch, loops
- `methods.md` — static/instance methods and overloading
- `collections.md` — List, Set, Map basics
- `exceptions.md` — try/catch and custom exceptions
- `file_io.md` — file read/write and try-with-resources
- `generics.md` — basic generics usage
- `threads.md` — simple threads with `Runnable`
- `getting_started.md` — quick compile/run tips and suggested commit message

How to use

1. Read the short explanation in the doc you want to study.  
2. In a terminal, compile and run the corresponding example file in `Java_Concepts/`:

   ```bash
   javac ExampleFile.java
   java ExampleFile
   ```
