# Methods: static, instance, and overloading

Key ideas

- Instance method: operates on a specific object instance and can access instance fields (non-static).  
- Static method: belongs to the class, not a single instance — useful for helpers.  
- Overloading: multiple methods with the same name but different parameter lists.

Example to run

- `Methods.java` — shows `add` (static overload) and an instance method `multiply`.

Tip

Remember: static methods cannot access instance fields directly; you need an object reference.
