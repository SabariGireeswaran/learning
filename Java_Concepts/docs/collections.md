# Collections: List, Set, Map

Key ideas

- List: ordered collection that can contain duplicates (e.g., `ArrayList`).  
- Set: unordered collection with no duplicates (e.g., `HashSet`).  
- Map: key → value storage (e.g., `HashMap`).

Example to run

- `CollectionsExample.java` — shows basic `List`, `Set`, `Map` operations and iteration.

Tip

Use the collection that matches your needs: `List` for order, `Set` to prevent duplicates, and `Map` to look up values by key.
