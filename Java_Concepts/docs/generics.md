# Generics: type-safe containers

Key ideas

- Generics provide type safety without casting (`List<String>` instead of raw `List`).  
- You can create generic classes like `Box<T>` to hold different types safely.

Example to run

- `GenericsExample.java` — `Box<String>` and `Box<Integer>` examples.

Tip

Generics remove many class cast errors and make code clearer and safer.
