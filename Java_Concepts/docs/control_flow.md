# Control Flow: if, switch, loops

Key ideas

- if / else: branching on boolean conditions.  
- switch: clear multi-branch selection for discrete values.  
- for, while, do-while: repeated execution until a condition is met.

Example to run

- `ControlFlow.java` — demonstrates `if-else`, `switch` and the three loop types.

Tip

Add print statements inside loops and conditionals to trace program flow while learning.
