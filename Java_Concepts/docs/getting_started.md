# Getting started: compile, run, and commit tips

Compile and run

1. Open a terminal in `Java_Concepts/`:  
   ```bash
   javac *.java
   java ExampleClass
   ```

2. Example: compile and run `HelloWorld`:
   ```bash
   javac HelloWorld.java
   java HelloWorld
   ```

Commit message suggestions

- Short: `feat(java): add beginner-friendly Java concept examples and docs`  
- Longer: `docs(java): add concise concept documentation and examples for OOP, control flow, collections, exceptions, I/O, generics, and threads` 

Small tips

- Use the `docs/` files for a quick conceptual reference.  
- Add or modify examples as you experiment; commit frequently with clear messages.
