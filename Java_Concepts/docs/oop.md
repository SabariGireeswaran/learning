# OOP: Classes, Constructors, Inheritance, Polymorphism

Key ideas

- Class: a blueprint for objects; contains fields (state) and methods (behavior).  
- Constructor: a special method used to initialize a new object.  
- Inheritance: one class can extend another and reuse/override behavior.  
- Polymorphism: using a subclass instance through a superclass reference to call overridden methods.

Example to run

- `ClassesAndConstructors.java` — shows a `Person` class and `toString()`/methods.  
- `InheritancePolymorphism.java` — shows `Animal` → `Dog` / `Cat` overriding `speak()`.

Tip

Try editing a constructor value and re-run to see how object state changes. Use `instanceof` to check runtime type when needed.
